# 🌍 Aurquartz — Geological Fieldwork Platform

A modern digital platform designed to streamline geological field data collection, organization, visualization, and export — all in one place.

## 🚀 Live Demo

👉 https://sadirkau.vercel.app/

---

## 📌 Overview

**Aurquartz** is a Geological Fieldwork Application built to replace the traditional workflow of using notebooks, scattered photos, GPS tools, and spreadsheets.

It provides geologists and Earth Science students with a **centralized, structured, and efficient digital field notebook**.

Instead of switching between multiple tools, users can:

> Collect → Organize → Visualize → Export
> all within a single platform.

---

## 🎯 Problem

Geologists in the field often face challenges such as:

* Data scattered across notebooks, mobile photos, and apps
* Missing or inconsistent GPS records
* Unstructured sample descriptions
* Difficulty reviewing data after fieldwork
* Time-consuming report preparation

---

## 💡 Solution

Aurquartz provides a complete and structured field workflow:

```text
Project → Locality → Sample → GPS → Photos → Notes → 
Mineralization → Alteration → Structural Data → Map → Data Table → Export
```

All data is organized, searchable, and ready for reporting or GIS usage.

## 🧩 Core Features (MVP)

### 📁 Project Management

* Create and manage geological field projects
* Assign project codes and field areas
* Organize all field data within each project

### 🧪 Sample Logging

* Automatic sample numbering (e.g. YSZ-SAM-001)
* Record rock type, field descriptions, and notes
* Link samples to locations or field stations

### 📍 GPS Integration

* Capture Latitude, Longitude, Elevation, and Accuracy
* Manual coordinate entry supported
* Accuracy validation to improve data quality

### 📷 Photo Documentation

* Attach multiple photos to samples or locations
* Add captions and classifications (sample, outcrop, etc.)
* Maintain visual documentation of field observations

### 🪨 Geological Data

* Rock type classification with structured input
* Mineralization tagging (e.g. sulfides, quartz veins)
* Alteration tracking (e.g. silicification, serpentinization)

### 📐 Structural Measurements

* Manual input for:

  * Strike / Dip
  * Dip Direction
  * Trend / Plunge
* Supports multiple structure types (faults, joints, veins, etc.)

### 🗺️ Interactive Map

* Display samples and locations on a map
* Clickable markers with summarized data
* Spatial visualization of fieldwork

### 📊 Data Table

* Structured table of all collected data
* Search, filter, and review records
* Clean data overview before export

### 📤 Export System

* CSV export (Excel & GIS ready)
* KML export (Google Earth compatible)
* PDF field reports including:

  * Project information
  * Sample data
  * GPS coordinates
  * Photos
  * Structural measurements
  * Map preview
